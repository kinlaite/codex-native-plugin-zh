# 原生插件中文化 · 恢复守护

这是“原生插件中文化”的配套插件，不是第二个翻译器。它只做一件事：**在主插件关闭或卸载后，于下一次 Codex 启动时恢复英文原值**。

## 为什么需要它

Codex 在关闭某个插件时，会立即卸载该插件的 MCP，并停止加载它的 hooks。主插件自己没有机会在“关闭”瞬间执行恢复。Codex 的 `SessionEnd` 也不是可靠的生命周期保证：禁用插件后 hooks 已被移除，插件被强制结束时也不会执行。

本守护插件是独立安装的普通 Codex 插件。关闭主插件不会关闭它，因此它在下次 Codex 启动时仍能收到 `SessionStart`，读取主插件留下的状态与备份，完成英文恢复。

## 行为

- 主插件开启时：不执行任何写入。
- 主插件关闭时：只恢复仍等于缓存译文的字段；用户编辑、已删除字段和上游新值会被跳过。
- 主插件卸载后：仍可从共享备份恢复，不会因为主插件代码被删除而失效。
- 恢复完成后保留翻译缓存、状态和备份，重新启用主插件即可再次写入中文。
- 不使用计划任务、常驻后台进程、外部服务或稳定运行目录。

## 安装

与主插件一起安装，并保持启用：

```powershell
codex plugin add native-plugin-zh@native-plugin-zh-local
codex plugin add native-plugin-zh-guard@native-plugin-zh-local
```

安装后需要在 Codex 中批准一次本插件的 `SessionStart` hooks。Codex 用插件内容哈希校验 hooks，插件更新后可能再次要求批准；这是 Codex 的安全边界。

## 数据

守护插件与主插件共享 `~/.codex/plugin-i18n-native` 下的状态、翻译缓存、备份和审计记录。它不创建第二份运行数据，也不修改 Codex 本体或任何插件清单；只读取共享状态与备份完成恢复。
